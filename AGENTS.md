# Agent entry point

1. Read [README.md](README.md), then follow [CONTRIBUTING.md](CONTRIBUTING.md). The same engineering, versioning, and review standards apply to human and agent contributions.
2. Read [HANDOFF.md](HANDOFF.md) and the relevant work order before editing. Verify the current branch, implementation status, and open PRs against GitHub; don't rely on an old handoff alone.
3. Use [CLAUDE.md](CLAUDE.md) for code landmarks and efficient local checks. Subsystem links live in the README.

Keep changes within the agreed work order. Report what was actually verified and what remains untested; don't claim a push, merge, deployment, or browser sign-off without checking it.
