# scalia-blueprint

Vehicles as data: blueprint types, layout, validation and meshes. Shipped blueprints are RON files in [`blueprints/`](../../blueprints/).

- Depends on: `scalia-core`.
- Key files: `types.rs`, `validate.rs`, `layout.rs`, `mesh.rs`, `shipped.rs`.
- Tests: `cargo test -p scalia-blueprint`.
