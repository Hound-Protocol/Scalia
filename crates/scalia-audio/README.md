# scalia-audio

Pack Engine acoustics: works out how a sound reaches the listener through the world (open field, street, room, corridor), including occlusion, distance and air. The browser audio graph in `web/audio.js` applies the results.

- Depends on: `scalia-core`, `scalia-ai`, `scalia-world`.
- Single file: `src/lib.rs`.
- Design docs: [docs/auralis-audio-engine.md](../../docs/auralis-audio-engine.md), [audio work orders](../../docs/work-orders/auralis-audio-workorders.md).
- Rule: audio never changes battle outcomes.
